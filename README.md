# Mail Spam Not

A machine learning project for detecting and classifying email spam using Python and Jupyter Notebooks.

## Overview

This repository contains tools and notebooks for building and evaluating spam detection models. The project uses data analysis and machine learning techniques to distinguish between legitimate emails and spam messages.

## Repository Structure

- **Jupyter Notebooks** (50.2%) - Interactive notebooks for data exploration, model development, and analysis
- **Python** (48%) - Core Python scripts and modules
- **HTML** (1.8%) - Documentation and visualization outputs

## Features

- Email spam classification and detection
- Data preprocessing and feature engineering
- Machine learning model development and evaluation
- Interactive analysis and visualization notebooks
