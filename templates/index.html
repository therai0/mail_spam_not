Mail Prediction ML Model

This Machine Learning project is designed to predict whether an email is Spam or Not Spam.

The model is trained on a dataset containing more than 33,000 email records. Different machine learning algorithms were tested, and Logistic Regression achieved the highest accuracy with an average performance of around 98%.

The system performs text preprocessing, feature extraction, and prediction to classify incoming emails efficiently.
